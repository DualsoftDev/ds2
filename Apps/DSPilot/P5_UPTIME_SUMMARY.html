③수식 — 한글 핵심

기준CT 분해 : 가동시간(CT) = 동작시간(MT) + 대기시간(WT)
A가용성 =Σ 실측 CTΣ 실측 CT + Σ 비가동 CT 비가동 CT = MT > CT이상치 인 사이클
P성능 =사이클 수 × CT이상치Σ 실측 CT CT이상치 = 14일 평균 표준CT
Q품질 = 양품수 / 총생산수 기본값 100% · 사용자 조정 가능 ✎
OEE = 가용성(A) × 성능(P) × 품질(Q)

④신뢰성 동반지표 — MTTR · MTBF

고장 onset = 사이클 시작 후 CT이상치 만큼 경과해 초과한 시점 (사이클 시작점 ✗)
MTTR평균 수리시간
고장 onset → 해당 flow 의 Call 에 going 변화 발생 시점
위 구간들의 평균 = 정지 1건당 평균 복구시간
MTBF평균 고장간격
고장 onset → 다음 비가동 CT 의 고장 onset
위 갭들의 평균 = 비가동 발생 평균 주기
두 지표 모두 비가동 CT 이벤트 의 onset 시각에서 자동 파생 → OEE 곱셈식과 독립인 신뢰성 동반지표로 대시보드에 함께 표시.

⑤사이클 시간 분해 → 비가동 판정 → MTTR · MTBF 구간

※ 비가동 사이클은 CT 전체가 비가동 CT(가용성 분모) — 앞 CT이상치(인식지연) · 고장(다운) · going 회복 후 정상동작 모두 포함. going 변화는 고장 종료(MTTR 끝점)이며, 그 이후 사이클 끝까지는 정상 동작하지만 해당 사이클은 비가동으로 집계됨.
※ 위 MTTR · MTBF 구간은 1건 예시 — 실제 지표는 모든 비가동 이벤트의 해당 구간들을 평균한 값.

⑥예시 시나리오 — 사이클 단위 OEE 산출 (STN3 조립3 설비)

📋 사이클 집계 (자동 수집)

CT이상치30s (14일 평균 표준CT) 🤖
총 사이클100 개
실측(정상)90 개 · Σ실측CT = 2,970s (49.5분)
비가동10 개 · Σ비가동CT = 1,200s (20분)
비가동 판정MT > 30s 인 사이클 10건 자동분류 🤖
품질기본 100% (사용자 조정 가능) ✎

🚨 비가동 CT 이벤트 (onset 기준)

onsetMT복구(going)
09:4275s+3.5분
10:1462s+4.2분
………
15:3070s+4.1분
MTTR = onset→going 복구 10건 평균 = 4.0분
MTBF = 연속 onset 간격 평균 = 21.0분

🧮 OEE 산출 (모두 자동)

가용성 = 71.2%
2,970 / (2,970 + 1,200) = 2970/4170
→ 비가동 CT 1,200s 만큼 가동 손실
성능 = 90.9%
(90 × 30s) / 2,970s = 2700/2970
→ 표준속도면 2,700s. 실제 2,970s → 속도손실 9%
품질 = 100%
기본값 (불량 미집계) · 사용자 조정 가능 ✎
OEE = 0.712 × 0.909 × 1.0 = 64.7%
→ 성능 양호, 가용성이 발목. 비가동 빈도(MTBF 21분) 개선 우선.
🔍 자동 인사이트: 이 설비는 성능(90.9%) 은 합격선이지만 가용성(71.2%) 이 OEE 의 발목을 잡는다. MT 가 표준 CT(30s) 를 넘긴 비가동 사이클이 10건 — 총 1,200s 의 손실. MTBF 21분 으로 약 21분마다 비가동이 재발하고, MTTR 4.0분 으로 복구는 빠른 편 → 잦은 짧은 정지(척찹·자재대기) 가 핵심 손실. 발생빈도(MTBF) 를 늘리는 것이 우선 개선점. 모든 수치는 사이클 단위로 자동 산출 — 품질만 기본 100% 에서 사용자가 보정.

⑦구현 순서

  • ① 사이클 적재시 MT(동작) / WT(대기) 분리 기록
  • ② CT이상치 = 14일 평균 표준CT 자동 산출 (ResolveEffectiveCycleRangeMs 재사용)
  • ③ 비가동 판정 — MT > CT이상치 사이클 플래깅 → 실측/비가동 CT 분리 집계
  • ④ OeeMath — 가용성·성능·품질·OEE 순수함수 (사이클 단위)
  • ⑤ MTTR/MTBF — 비가동 onset 시각 + Call going 변화 시점으로 구간 산출
  • ⑥ UI /app/uptime.html — 3대 지표 + 동반지표 카드

⑧비목표 · 가정

  • 품질(Q) — 기본 100%, 사용자 조정만 (불량 자동집계는 향후)
  • MTTR/MTBF 는 OEE 곱셈식에 미포함 (독립 동반지표)
  • CT이상치 14일 평균 — DB 영구기입 금지 (RAM only)
  • 비가동 판정 기준은 MT (동작시간) 단독, WT 미포함
  • CCTV / 품질자료 연계 — P5 외부
