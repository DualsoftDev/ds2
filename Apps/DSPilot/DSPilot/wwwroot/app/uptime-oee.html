고장·비생산 판정 기준

한 사이클 =
동작 MT설비가 움직인 시간 + 대기 WT동작을 마치고 다음 사이클까지 서 있던 시간
동작이 늘어지면 → 고장  ·  대기가 길면 → 비생산  ·  나머지는 정상
  1. 1
    동작(MT)이 평소의 초과 → 고장사이클 전체가 손실(가용성 A), 고장 건수·평균 간격에 반영. 아무리 길어도 비생산으로 바뀌지 않음 — 주말 방치는 정지 로그에서 전환.
  2. 2
    아니면 대기(WT)가 평소의 이상 → 비생산생산 계획이 없던 시간(무오더·교대·주말)으로 보고 가용성 분모에서 제외. 하한 = 평소 사이클 개분.
  3. 3
    나머지 → 정상경계 아래의 느린 동작·긴 대기는 가동으로 인정 — 속도 저하는 성능(P)이 흡수합니다.

고장> × 비생산 전환 없음
고장 배수 동작시간이 14일 평소(중앙값)의 를 넘긴 사이클을 고장으로 봅니다(사이클 전체가 손실). 아직 끝나지 않은 사이클이 이 기준을 넘기면 정지 로그에 '진행 중'으로 표시되고, 다음 사이클이 시작되는 순간 완료 행으로 확정·분류됩니다. 1초 미만은 지터로 보고 무시합니다.

정상< × 평소 대기
비생산 (제외)≥ ×
비생산 배수 사이클의 대기가 평소(중앙값)의 이상이면 비생산으로 보고 가용성 분모에서 뺍니다. 낮출수록 대기가 분모 밖으로 빠져 가용성이 후해지니 주의 — 정지 로그의 고장으로/비생산으로 전환(수동 확정)은 항상 이 기준보다 우선합니다.

정상 가동시간을 얼마나 수집했는가 — OEE·TEEP 와 별개 축(지표에 반영되지 않음)
tune 설계 결정 — 두 규칙 · 사이클 단위 OEE (doc/28) & 정직성 원칙
모델 (2026-09-11, doc/28)두 규칙 · 사이클 단위 — 사이클 = 동작(MT) + 대기(WT). 동작이 평소(14일 중앙)의 고장배수를 넘으면 고장, 대기가 비생산배수 이상이면 비생산, 나머지는 정상. 판정·손실·표시·전환의 단위는 사이클 행 하나(행 안에서 고장이 언제 시작됐는지는 모른다 — 쪼개지 않는다). 수집된 정상 가동만 근거로 삼고 못 본 시간에는 어떤 상태도 주장하지 않는다.
OEE = A × P × QA = 가동 ÷ 생산가능(캘린더 − 비생산 − 미계측 − 진행 중) · P = (N × 표준 CT[14일 중앙]) ÷ Σ실측 CT · Q = 양품/총생산(기본 100% 가정). 한 요소라도 미산출이면 OEE = '—'. 비가동 = 생산가능 − 가동 = 고장 + 유지보수.
완료 신호 없는 사이클시작 → 다음 시작(불인정 행)은 동작·대기를 나눌 수 없어 사이클 전체 길이를 중앙 CT × 같은 배수에 댄다. 동작 기준선에 대면 대기 비중이 큰 설비(셔틀 87%)에서 정상 길이 사이클도 완료 신호 한 번 누락에 고장이 된다.
고장은 승격 없음길이가 아무리 길어도 고장은 비생산으로 바뀌지 않는다 — 끄고 간 정지와 고장 조치는 행으로 구분할 수 없기 때문. 대신 길이가 비생산 기준 이상인 고장을 '확인 필요'로 표시하고, 정지 로그에서 행을 골라 비생산으로 전환하거나 고장으로 확정한다(수동 라벨은 자동 판정에 우선, 재도출 후에도 과반 겹침으로 같은 행에 붙는다).
표준 CT최근 14일 정상 사이클 CT 중앙값(flow별, RAM only). 평균은 정지를 머금은 사이클에 끌려 P 가 100% 에 고정됐다. 완료 사이클 10건 미만이면 판정 보류(전부 정상 — '판정 보류' 배지), 0개면 '—'.
입력은 합집합CT 를 단순 합산하지 않고 구간 union 으로 잰다. 수집이 오염되면 사이클끼리 겹쳐 합이 달력을 넘는다 — union 은 창을 넘을 수 없다. 카빙 사슬 = 미계측 ▸ 비생산 ▸ 형제가동 ▸ 진행 중 ▸ 비가동.
미귀속 = 0비가동 − 유지보수 − 고장은 정의상 0 이어야 한다(행이 연속 + 고장 행 전체 적립). 0 이 아니면 데이터 결함(행 겹침·누락·재시작 조각) — 종전 '가동간 공백' 세그먼트는 삭제하고 데이터 무결성 카드의 진단 항목으로 보낸다.
사이클 0건이면산출 불가. 근사값을 만들지 않는다 — 종전 달력근사 폴백은 "정지가 감지되지 않았다"를 "100% 가동"으로 번역해, 측정 자체가 안 되는 설비를 만점으로 표시했다.
고장 사이클 평균 시간 / 평균 고장 간격고장 행에서만. onset = 행 시작, 평균 시간 = 고장 행 전체 길이(ct) 평균(정상분 포함 — 초과량은 행 노트). 유지보수 꼬리표 행은 통계에서 제외(A 손실은 유지). OEE 곱셈식과 독립 동반지표. 0건이면 "🟢 고장 없음" 배지(가짜수치 금지).
데이터 무결성 분리"얼마나 봤나"는 지표가 아니라 수집 상태다. A·P·Q 에 섞지 않고(손실로 넣으면 계측 실패가 설비 탓, 분모에서 빼면 계측이 나쁠수록 설비가 좋아 보임) 페이지 맨 아래 데이터 무결성 카드가 수집률·미귀속으로 따로 보고한다.
필수 입력 0개표준 CT·고장/비생산 판정·A·P·고장 사이클 평균 시간·평균 고장 간격 모두 수집 데이터로 자동. 품질%·표준 CT 수동입력·고장/유지보수 구분·전환은 선택(보정). 사용자가 움직이는 배수는 고장·비생산 2개.
