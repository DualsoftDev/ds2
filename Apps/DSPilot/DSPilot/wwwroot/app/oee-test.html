OEE = A × P × Q변경 v3 의 'Q 제거'를 사용자 요청으로 복원 — Q 곱 부활. 기본 100% 가정(assumed), 불량율/품질 직접 입력 시 측정값(measured)으로 전환. (기존 6/10 구현과 동일 정책)
5 KPI변경 OEE·A·P·Q·MTBF. MTTR만 제거. Q 카드 = '가정/사용자' 칩 + 톤 중립(가정은 초록 금지). 데이터 계층(oeeProductionCount·불량입력) 활용.
MTBF 무고장보정 v3 의 max(n,1) 은 무고장 시 가짜 MTBF → 정직성 위배. FailureCount=0 이면 "🟢 무고장" 배지.
계획시간 분모보정 분모가 이미 3중(달력/시프트/자동). 단일 폴백 체인으로 통일. "시프트 미설정" 판별 위해 UserSet 마커 신설.
표준CT 중앙값보정 v3 "기존" 표기 오류 — 미구현. 신설하되 "임시" 라벨 후 30샘플서 p10 승급.
분류 출처보정 classifySource 신규(테이블=oeeDowntimeEvent). 수동 분류 가드를 휴리스틱보다 먼저 도입.
abnormal·usertag검토 정지 소스로는 비권장 — 점 이벤트라 onset만, clear 시각·duration 영속 안 됨(userTagAlertLog 1행). 정지 구간을 만들면 nocycle/고장비트와 이중계상(dedup 코드 0)+필터 의존 MTBF 비결정. 대신 시간겹침 단서(원인 라벨링)로만 활용 — 건수·MTBF 불변. usertag 정지화는 FaultBitAddresses 등록이 정본.
