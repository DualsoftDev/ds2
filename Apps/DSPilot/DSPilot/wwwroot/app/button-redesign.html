버튼 재설계 후보 비교

같은 버튼 세트를 4가지 스타일로 렌더 · "버튼으로 확실히 인지되는가"가 기준

현재 지금 적용됨

투명 배경 · 2px 각진 모서리 · 얇은 선. → 보조 버튼이 라벨/셀처럼 보여 클릭 요소로 인지 어려움.

A · 솔리드 + 라운드 모던 SaaS · 가장 명확

모든 버튼에 배경 채움(보조=연회색) · 8px 둥근 모서리 · 부드러운 그림자 · 눌림 애니메이션. 누구나 버튼으로 인지.

B · 입체 테크니컬 브랜드 유지 · 떠오름

HUD 감성(6px)을 유지하되 흰 배경 + 그림자로 물리적으로 "떠 있는" 버튼. hover 시 살짝 올라오고 액센트 테두리.

C · 틴트 액센트 색으로 신호

보조 버튼도 애저 틴트 배경 + 애저 테두리/글씨 → 모든 버튼이 "색이 있는 = 누를 수 있는" 신호를 줌. 주 버튼은 솔리드.
