버튼·컨트롤 템플릿

DSPilot 공용 스타일(ds.css → swiss.css) 실제 렌더 · 클래스명 함께 표기

1 · 기본 버튼

베이스 클래스 .btn + 스타일 변형. 아이콘은 .material-icons.

.btn .btn-filled
주 액션(Primary). .btn-primary 도 동일.
.btn .btn-outlined
보조 액션. 테두리 = 액센트.
.btn
중립(default) 테두리·텍스트.
.btn .btn-outlined .color-default
액센트 대신 회색 테두리.

2 · 색상 변형 (.color-*)

의미 색상. filled/outlined 에 .color-warning / success / error / info / secondary 조합.

.btn-filled .color-success / .color-warning / .color-error
.btn-filled .color-info / .color-secondary
.btn-outlined .color-*

3 · 크기

기본 vs .btn-sm. 아이콘 전용은 .btn-icon.

.btn-filled / .btn-filled.btn-sm
.btn-icon / .btn-icon.btn-sm
정사각 아이콘 버튼(38px / 30px).

4 · 상태 (hover / active / disabled / focus)

실제 CSS 상태 — 마우스를 올리거나 Tab 키로 포커스 이동해 확인하세요. 비활성은 disabled 속성.

:hover — 배경 진해짐
.btn-filled[disabled] — opacity .45
이번 통일로 추가된 상태.
.btn-outlined[disabled]
:focus-visible — 액센트 아웃라인 링

5 · 세그먼트 컨트롤 (토글 버튼 그룹)

공용 .segmented + 별칭 .ct-seg(flow-all) · .hm-seg(heatmap) — 모두 동일 룩으로 통일됨. 클릭해 보세요.

.segmented > button.active
.segmented (아이콘 포함)
.segmented (3개 이상)
uptime 은 .btn-filled/.btn-outlined 토글 방식도 사용.

6 · 토글 스위치 (.switch)

on/off 설정용. 이번 통일로 확대(42×22)·노브 그림자·포커스 링 추가.

.switch > input[checkbox]:checked
.switch (off)
.switch.color-warning
.switch input:disabled

7 · 체크박스 · 라디오

네이티브 입력 — 전역 accent-color: var(--color-primary) 로 애저 통일.

input[type=checkbox]
input[type=radio]

8 · 칩 · 필 · 상태 태그

비버튼 라벨. .chip* (테두리형) · .ds-pill (미니 라벨) · .pw-chip* (상태).

기본 정상 주의 오류 정보
.chip .chip-primary/success/warning/error/info
가동시간 14일평균 사용자
.ds-pill
OK RUN WARN ERR IDLE STOP
.pw-chip .pw-chip-ok/run/warn/err/idle/stop
components.css / pw.html 전용(공용 아님).

9 · 폼 컨트롤

입력·선택. .form-field · .form-select.

.form-field
.form-field.form-select

10 · 페이지 전용 특수 버튼

공용 CSS 가 아니라 각 페이지 인라인 스타일에 정의됨(참고용으로 복사 표시).

.ct-tag-btn.head.active / .tail.active — flow-all
Head=초록 · Tail=보라 (의미색, 통일 대상 아님).
100%
.ct-zoom — flow-all 줌 스테퍼
.fa-controls-toggle — flow-all 접이식 헤더
