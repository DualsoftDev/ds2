🎯 동작 시퀀스 (User Interactions)

  1. ① 요약 셀 클릭 — 최대시간·최소시간·최대 대기율 셀을 클릭하면 좌측 도면 레이아웃에서 해당 Flow 카드가 빨간 테두리·노란 배경으로 강조됨. (예: B-3 카드 highlight)
  2. ② Flow 카드 클릭 — 카드 클릭 시 우측에 MT/WT/CT 시간 정보 + 대기율 + 최근 10 사이클 히스토리 내역이 펼쳐짐.
  3. ③ 상세 버튼 — 카드 안의 상세 보기 → 버튼 클릭 시 P3 사이클 분석 페이지로 이동 (Flow ID query 파라미터 포함).
  4. ④ 자동 새로고침 — 5초마다 모든 KPI·차트·도면이 자동 갱신. 우측 상단 🔄 새로고침 (5s) 버튼으로 수동 갱신 가능.
  5. ⑤ 막대 클릭 — 우측 비교 차트의 막대 클릭도 좌측 도면 강조와 동일한 효과 (양방향 동기화).
