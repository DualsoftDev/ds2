# Plan mode
## device 선지정
:plan
- 공정: Zone1, Zone2, Zone3
- Robot device Rb1: Home, Work1, ..., Work9
- cylinder device : [Z{i}Cyl{j}]
Part 가 Zone1, Zone2, Zone3 에서 순차로 이동하는 시스템 모델링
Zone1에서 두개의 Z1Cyl1, Z1Cyl2 cylinder 가 동시 전진 후, Rb1 Work1 -> Work2 -> Home 수행 후 두 실린더가 동시 후진
Zone2에서 세개의 Z2Cyl1, Z2Cyl2, Z2Cyl3 cylinder 가 동시 전진 후, Rb1 Work3 -> Home 수행 후 Puncher 가 Punch 후 세 실린더가 동시 후진
Zone3에서 네개의 Z3Cyl1, Z3Cyl2, Z3Cyl3, Z3Cyl4  cylinder 가 동시 전진 후, Rb1 Work4 -> Home 수행 후 Puncher 가 Punch 후 네 실린더가 동시 후진



전체 시스템에 필요한 요소는 다음과 같다. 
- 공정: Zone1, Zone2, Zone3
- Robot device Rb1 의 행위: Home, Work1, Work2
- cylinder device : [Z{i}Cyl{j}]
- Puncher device : Punch, Reset
- Sprayer device : Spray, Reset

part 가 Zone1, Zone2, Zone3 에서 순차로 이동하면서 각 zone 에서 작업하는 시스템 모델링
Zone1에서 두개의 Z1Cyl1, Z1Cyl2 cylinder 가 동시 전진 후, Rb1 Work1 -> Work2 -> Home 수행 후 두 실린더가 동시 후진
Zone2에서 두개의 Z2Cyl1, Z2Cyl2 cylinder 가 순차 전진 후, Rb1 Work3 -> Home 수행 후 Puncher 가 Punch -> Reset 수행 후, 두 실린더가 동시 후진
Zone3에서 Z3Cyl1 cylinder 가 전진 후, Sprayer 가 Spray -> Reset 수행 후 실린더가 동시 후진




:plan
- 공정: Prep, Paint, Dry
- Robot device Rb1: Home, Path1, ..., Path6
- cylinder device: [P{i}Cyl{j}]
- Sprayer device: Spr1 (SPRAY)
- Heater device: Htr1 (ON, OFF)
Part 가 Prep, Paint, Dry 에서 순차로 이동하는 시스템 모델링
Prep 에서 두개의 P1Cyl1, P1Cyl2 cylinder 가 동시 전진 후, Rb1 Path1 -> Home 수행 후 두 실린더가 동시 후진
Paint 에서 세개의 P2Cyl1, P2Cyl2, P2Cyl3 cylinder 가 동시 전진 후, Rb1 Path2 -> Path3 -> Home 수행 중 Spr1 이 SPRAY 후 세 실린더가 동시 후진
Dry 에서 한개의 P3Cyl1 cylinder 가 전진 후, Htr1 이 ON 후 Rb1 Path4 -> Path5 -> Home 수행 후 Htr1 이 OFF 후 실린더가 후진
Rb1의 경우 각 Work에 대해 상호 리셋관계여야 함 
Sprayer device: Spr1 (SPRAY) 같은 경우 작업이 끝나면 리셋이 되어야 함
