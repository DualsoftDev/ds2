Why MinGW64 and not MS64: the VS2022/MS64 build imports VCRUNTIME140.dll, which is not part of
Windows and is not installed by the .NET 9 runtime; the MinGW64 build depends only on msvcrt.dll/
KERNEL32/USER32, so it loads on a clean PC without the VC++ redistributable.

How it is used: loaded dynamically (P/Invoke, DllImport "libusb-1.0") by Ev2.PLC.Usb.dll when an
LS XGT PLC is collected over the CPU front USB loader port. It is not statically linked into any
DualSoft binary; replacing this file with another LGPL-compatible libusb 1.0 build is supported
(LGPL-2.1 §6). Source code for libusb is available at the URL above.
