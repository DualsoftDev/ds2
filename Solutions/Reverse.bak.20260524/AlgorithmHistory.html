Capacity — 캐파 다양화 + Bimodal stability Bottleneck

신규 도전: 캐파 N 의 pipeline 라인 — 한 사이클 안 같은 변수가 N 번 발화 (token interleaving). 캐파 1~20, jitter, oscillation, bottleneck 패턴.

발견: c12_bottleneck — S2 stage 에 queue 형성. 첫 token 의 S1→S2 lag = 200ms, 두 번째 token = 500ms (대기). lag 분포가 bimodal. 표준 CV/std gate fail (CV=0.44, std=155).

알고리즘 강화 — Bimodal Stability:

let bimodalStable =
    sorted lags → find largest gap → split into mode1, mode2
    // 3 조건 모두 통과해야 인정:
    if maxGap ≥ 150ms                          // 두 mode 명확 분리
    && smaller_mode ≥ 25% of total             // outlier 가 아닌 진짜 modal
    && stdOf(mode1) < 50ms                     // mode 내 안정
    && stdOf(mode2) < 50ms
    then bimodal = true

let stable = (cv ≤ 0.30) || (std ≤ 150ms) || bimodalStable

D1~D5 의 confounded 가 잘못 통과 위험: bimodal split 으로 통과 가능. → 3 조건 (gap + size + mode std) 으로 진짜 bottleneck vs 가짜 bimodal 구별. confounded 의 mode std (~60ms) > 50ms → fail.

Logic Graph — 재귀 expand + AND/OR 강도 Symbolic enrichment

사용자 요청: "직접 연결도 있지만 재귀적으로 연결을 추적해서 결국에 몇 level 연결에 연결되어있나 and or 해석해서 강한 연결이나 정보도 인과관계해석에 포함되는 알고리즘"

신규 모듈 LogicGraph.fs:

  • LogicExpr discriminated union: LVar | LAnd | LOr | LNot
  • 재귀 expand: rung 변수 정의를 cycle 방지 + max depth 제한으로 재귀 평탄화
    B = A AND X, C = B AND Y → C = A AND X AND Y (3-input AND)
  • AND/OR 강도: AND child 들 = currentStrength 유지, OR child 들 = currentStrength / N
    • AND-only path → 1.0 (모든 input 필요)
    • OR 2-branch 거치면 → 0.5
    • OR 5-branch → 0.2 (5-way OR 각 input)
  • extractCandidates: strength ≥ threshold (기본 0.3) 인 input → 후보 arrow
  • ReverseEngine.Input 확장: LogicRungs : LogicRung list option 옵션

9.2 Drift Detection

lag 가 시간 따라 단조롭게 변화 (linear drift) 면 일반 stable 게이트 실패. Linear regression 으로 drift 인식.

let driftStable =
    // lag(i) = slope*i + intercept
    let slope, intercept = linear_regression i_values lag_values
    let residualStd = std(lag(i) - (slope*i + intercept))
    // 인정 조건:
    residualStd < lagMean * 0.15   // residual 이 mean 의 15% 이하
    && abs slope > 0.5              // slope 의미 있음 (drift 존재)

let stable = cv ≤ cv_max
          || smallLagFallback
          || bimodalStable
          || driftStable           // ← 신규

검증:

  • D3.0 linearDrift: lag 100 → 700ms (cycle 당 +10ms). 이전 std 173 으로 drop → 이제 driftStable 통과 ✓
  • 다른 D3 케이스 (random walk, step jump, spike) 는 residual std 큼 → drift X (정상 drop 유지)

10. 향후 확장 가능 영역

  • 4+modal lag: tri/quad-modal stability (현재 bimodal 만)
